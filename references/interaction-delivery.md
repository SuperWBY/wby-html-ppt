# 交互与交付合同

## 固定功能及边界

- ←/→：上一页/下一页；首页末页禁用相应按钮。可附加 PageUp/PageDown/空格。
- 全屏按钮/F：切换 Fullscreen API；不支持或被拒绝时显示可理解说明，不假装成功。
- O：开关总览。缩略图、页码、标题、当前页标记，点击跳转；窄屏滚动，缩略图比例不被挤压。
- Esc：浏览器退出全屏或关闭最上层对话框。截图浮层打开时不翻页。
- 图片：为需放大的截图使用 `<a class="image-link" href="assets/example.png"><img ...></a>`。完整图加载并支持关闭。
- 外部链接：使用真实 `<a href="https://..." target="_blank" rel="noopener">`，或者有明确地址的 `button[data-url]`。不为离线打包下载私密页面。
- 复制可选：按钮用 `data-copy-target="#提示词元素ID"`。失败时给出选中复制提示。
- 输入框、可编辑区域、组合键不被截获；按住 O/F 不反复切换。
- iframe 焦点下快捷键有效；总览缩略图 iframe 不接管鼠标/键盘。

## 动画

模板支持轻量页面与总览过渡，遵守 reduced-motion。页面可自行实现局部 CSS/SVG 动画；不能依赖动画才能读取最终文字。模板会给嵌入页补充 reduced-motion 样式。
不自动播放音频、自动翻页或绑定难以发现的手势。若使用分步显现，不抢占约定的左右翻页和 O/F 按键；提供明确的下一步按钮。

## 打包输入和支持范围

迁移旧课件时，将依赖旧播放器硬编码映射的按钮改为真实 a 链接或 button[data-url]，复制按钮改为 data-copy-target；不要把案例专属链接写进通用播放器。

build.py 使用 JSON 的 title 和 slides 数组。输入页面是可信、已审阅的项目代码，不要直接执行第三方完整 HTML。
支持：本地 stylesheet、普通 script、img/src 和本地图片 href、style 标签和样式表中的 CSS url()；资源限定项目目录内，去重后嵌入单文件。CSS 中的路径按该 CSS 所在目录解析。
不支持：ES module/import、动态 fetch、CSS @import、srcset、外部嵌入资源、页面相对导航等。先把源代码转成静态可打包形式或使用专门构建工具；不要简单关闭检查。远程超链接允许保留。

交付源项目和独立 HTML；可附源码包，不把公开发布当作打包的一部分。报告页数、体积、使用方式及实测限制。转发文件，不转发 localhost 地址。接收者下载后用现代桌面浏览器打开；聊天内预览可能不执行脚本。

## 有意义的验证

1. 清单顺序/数量与用户确认一致，缺文件和越界路径应失败。
2. 浏览器检查典型页面和新增页，注意不同窗口比例、投影字号、图片完整性。
3. 左右键、iframe 焦点、边界、O 开关、缩略图跳转、Esc、图片放大、全屏进入/退出。
4. 确认所有必需资源已内嵌，没有运行时指向原项目的依赖；外部超链接保持可点击。
5. 优先检查离线打开的最终产物。浏览器禁止本地文件时不可绕过；可用 HTTP 检查嵌入后的文件，明确本地离线打开未实测。
6. 使用系统减少动态偏好时，内容仍完整可读。不要把仅静态检查通过描述为所有浏览器已验证。
